# Sprint_7
Автоматизированные тесты API сервиса аренды самокатов

## Предварительные требования
- Python 3
- Firefox

## Зависимости Python
pip install -r requirements.txt

## Тестовые сценарии

### 1. Создание курьера (test_courier_create.py)
- Успешная регистрация нового курьера
- Попытка создания дубликата курьера
- Создание курьера без обязательных полей

### 2. Авторизация курьера (test_courier_login.py)
- Успешный логин с валидными данными
- Авторизация с некорректными логином/паролем
- Попытка входа без обязательных полей

### 3. Удаление курьера (test_courier_delete.py)
- Успешное удаление курьера по ID
- Попытка удаления с несуществующим ID
- Удаление без указания ID

### 4. Создание заказа (test_order_create.py)
- Параметризованные тесты с различными цветами самоката
- Создание заказа со случайными данными
- Проверка присвоения трек-номера

### 5. Получение заказов (test_orders_list.py)
- Получение списка всех заказов
- Проверка непустого списка заказов

### 6. Получение заказа по номеру (test_order_get_by_number.py)
- Создание заказа и получение его по трек-номеру
- Валидация структуры ответа

### 7. Поиск заказа (test_order_get.py)
- Получение заказа по ID
- Поиск несуществующего заказа
- Запрос без номера заказа

### 8. Принятие заказа (test_order_accept.py)
- Успешное принятие заказа курьером
- Попытка принятия без ID курьера/заказа
- Принятие с некорректными ID

### 9. Поиск станций метро (test_metrostation_search.py)
- Поиск станций по названию

### 10. Проверка работы сервера (test_ping.py)
- Проверка доступности API
